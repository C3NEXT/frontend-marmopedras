# Marmopedras — Next.js

Projeto convertido de React/Vite + TypeScript para **Next.js + React + JavaScript + JSX + CSS**.

## Tecnologias

- Next.js
- React
- JavaScript
- JSX (HTML dentro do React)
- CSS / Tailwind CSS v4

## Executar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.
